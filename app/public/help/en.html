Simulation Control

  • Start – starts the simulation. Units with assigned routes will begin moving.
  • Pause – pauses the simulation. Units remain at their current positions.
  • Stop – stops the simulation and resets all units to their starting positions.
  • Step – advances the simulation by one tick (250 ms). At 1× speed, a unit travelling at v km/h covers v ÷ 14,400 km per step (e.g. 45 km/h → 3.1 m, 30 km/h → 2.1 m, 10 km/h → 0.7 m).
  • Speed – simulation speed multiplier (1× to 1000×). Default value is 10×.

Map Controls

  • Click on a unit – displays unit information in the right panel.
  • Click on selected unit again – deselects it.
  • Click on empty map (no unit selected) – opens the Add Unit dialog at the clicked position.
  • Click on empty map (with a mobile unit selected) – adds a waypoint. The cursor changes to a crosshair.
  • Delete key (with a unit selected) – permanently removes the selected unit.

Routes

Routes can only be assigned to mobile units (speed > 0 km/h). Static units cannot have routes.

Unit Types

  • Infantry – dismounted infantry unit (X symbol).
  • Armor – tank or armored vehicle unit (oval symbol).
  • Artillery – field artillery battery (filled circle symbol).
  • Reconnaissance – recon platoon or unit (magnifying glass symbol).
  • Engineer – engineer company (E symbol).
  • Friendly units are displayed in blue, hostile units in red.

File

  • Export – saves the current starting positions and unit routes to a JSON file.
  • Load from File – restores positions and routes from a previously exported JSON file. The simulation will be stopped.

Tools

  • Measure Distance – opens a dialog to calculate the distance between two units. Displays a minimap with both unit positions and the connecting line.

Data Log

The Data Log panel shows simulation events. Use the toggle buttons in the header to filter categories:

  • System – simulation start, pause, stop, unit added/removed events.
  • Route – waypoint added, end of route reached.
  • Position – current coordinates of moving units (once per second).
